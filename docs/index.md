# Quick File Upload

Quick File Upload adds an upload pad to Foundry VTT. Drop local files, select a batch from disk, or paste images and text. Ordered filename and size rules choose the server folder; optional actions share images, create journal pages, or run macros.

This handbook describes **version 1.14.1**, primarily for Foundry VTT v14. The manifest also permits v13. English and German interface translations are included; instructions below use English labels.

## Start here

Follow [[installation|Installation and permissions]], then [[quick-start|Your first upload]]. A GM can start with the default `assets` folder and add routing rules later.

## Choose a workflow

- **Sort maps and portraits:** configure [[groups-and-rules]], then copy a pattern from [[regex-examples]].
- **Paste a handout:** configure [[clipboard-import]] and [[filename-builder]], then add an action from [[upload-actions]].
- **Share an uploaded image:** use [[file-browser|Show to players in the file browser]].
- **Move your configuration:** follow the complete restore procedure in [[settings-transfer]].
